# Agent: Visão Geral do Jogo

## Objetivo
Planejar o RPG narrativo de ficção científica com tempo reverso, focado em encontros temporais, escolhas e economia de fases.

## Pilars
- Narrativa fechada em 20 anos (2026-2046)
- Encontros sincronizados a cada 5 anos
- Dois protagonistas com fluxos temporais opostos
- Escolhas que alteram fricção temporal, sincronia e finais
- Interface de menu + save por fases + itens clicáveis

## Estrutura principal
1. Menu inicial
2. Salvar por fases / capítulos
3. Mapa de cenas lineares com desvios
4. Conversas ramificadas
5. Cenários com hotspots clicáveis
6. Inventário minimalista e itens narrativos

## Conteúdo de referência
Usar as seções de ato, personagens e finais do `docs/Reverb-Game.md` como base.

## Resultados desejados
- Documento de planejamento pronto para pré-código
- Arquivo por domínio de agente
- Organização otimizada em 5 MDs
