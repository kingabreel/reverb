# Agent: Cenários e Mapas

## Estrutura de mapas
- 8 mapas principais
- 3-6 cenas por mapa
- Cada mapa = bloco narrativo + meta de objetivo
- Retorno visual ao mesmo ambiente para economia de assets

## Mapas planejados
1. Ruínas / Encontro inicial
2. Escola / rotina quebrada
3. Eco da criança / paradoxo inicial
4. Arquivos proibidos / conspiração
5. Observatório / Ponto de Sincronia
6. Linha quebrada / guerra temporal
7. Último acesso / preparação final
8. Núcleo / decisão final

## Cenários por mapa
- Cada cenário tem:
  - 1 pano de fundo principal
  - 2-4 hotspots clicáveis
  - 1 evento de conversa ou escolha
- Exemplo: Ruínas
  - fragmento metálico
  - luz pulsante
  - Lyra caída
  - relógio no chão

## Itens clicáveis
- Objetos que desencadeiam:
  - descrições de lore
  - notas de diário
  - pistas de investigação
  - pequenas cinemáticas
- Tipos:
  - Interagir (coletar item / registrar)
  - Examinar (texto + clima)
  - Ativar (acionar dispositivo / entrada)

## Transição de fases
- passagem entre cenas via curto fade + texto de tempo
- escolhas-chave definem próximo mapa
- cenário final de cada fase serve como gatilho de save

## Economia de tokens / assets
- Reusar cenários: escola, laboratório e ruínas aparecem com variações
- Objetos persistentes acendem de forma diferente conforme progresso
- Cenas pequenas e focadas, evitando open world
