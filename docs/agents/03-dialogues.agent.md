# Agent: Conversas e Narrativa

## Sistema de diálogos
- Árvore de diálogo simples com ramificação em 3 níveis
- Cada nó contém:
  - Texto do personagem
  - 1-3 respostas do jogador
  - Estado de saída (sincronia / confiança / informação)
- Conversas críticas afetam fases seguintes

## Tipos de conversa
- Exposição: entregar lore e missão
- Confronto: escolhas narrativas e confiança
- Revelação: plot twist e estatísticas de final
- Relembrar: memórias entre Kael e Lyra

## Personagens e relacionamentos
- Kael: protagonista linear
- Lyra: contraponto reverso
- Arthur Vance, Vesper, Maya, Jude, Echo-07
- Cada NPC tem uma linha básica de reação às ações do jogador

## Estrutura de cenas de diálogo
- Cena 1: Encontro inicial (Lyra 35 / Kael 15)
- Cena 2: Eclipse 2031 (Lyra 30 / Kael 20)
- Cena 3: Ponto de Sincronia 2036
- Cena 4: Eclipse invertido 2041
- Cena 5: Núcleo 2046

## Mensagens de fase
- Cada capítulo começa com uma frase tema e objetivos curtos
- Informações do save mostram resumo do momento e stakes

## Planejamento de escolhas
- Macro: dizer a verdade, cooperar, confrontar
- Micro: contato físico, mostrar item, recusar ajuda
- Exemplo:
  - "Mostrar o relógio" → aumenta confiança; reduz surpresa
  - "Mentir para Jude" → salva segredo; diminui lealdade

## Fluxo de diálogo otimizado
- Sempre 2-3 linhas de texto por bloco para ritmo rápido
- Use descrições sensoriais curtas em vez de longos parágrafos
- Evite redundância entre diálogos em diferentes fases
