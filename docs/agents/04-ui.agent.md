# Agent: Interface e UX

## Menu inicial
- Layout:
  - Logo do jogo
  - Botões principais
  - Status do último save
  - Fundo com ruínas e relógio invertido
- Acessibilidade:
  - teclado / gamepad básico
  - contraste alto

## Tela de fase
- Cabeçalho com capítulo, ato e objetivo
- Lista de itens coletados / pistas
- Botão de save manual
- Acesso rápido ao inventário

## Inventário
- Seção pequena com max 6 itens
- Cada item revela descrição e uso narrativo
- Itens clicáveis com ícone + label

## Sistema de hotspots
- Cursor muda ao passar sobre objeto clicável
- Tooltip curto: "Examinar relógio" / "Abrir gaveta"
- Feedback visual imediato ao clicar

## Tela de carregamento
- Mostra imagem do cenário anterior
- Texto curto: "Capítulo 3 — Ponto de Sincronia"
- Dica de jogabilidade / lore

## Feedback de escolhas
- Mostra resultado claro após decisões importantes
- Ex: "Sincronia aumentada" / "Fricção entrópica ativa"
- Indicadores discretos na HUD

## Organização otimizada
- UI minimalista para jogo narrativo
- Evitar inventário complexo
- Priorizar leitura e escolha rápida
