# Agent: Sistemas de Jogo

## Menu inicial
- Tela estática com título, subtítulo e opções:
  - Continuar
  - Novo Jogo
  - Carregar Fase
  - Opções
  - Créditos
- Estilo: sci-fi limpo, relógio invertido como elemento visual

## Save por fases
- Save simples por capítulo / mapa
- Cada fase é um checkpoint narrativo:
  - Cap 1: Encontro inicial
  - Cap 2: Investigação
  - Cap 3: Ponto de Sincronia
  - ...
- Slots de save: 3+ por jogador
- Tela de carga mostra resumo curto do momento

## Loop de jogo
1. Carregar fase
2. Explorar cenário
3. Interagir com objetos clicáveis
4. Conversar com NPCs
5. Tomar decisão crítica
6. Avançar para próxima fase ou condição de falha

## Sistema de escolhas
- Dois níveis:
  - Macro: impacto em Sincronia / Ruptura / final
  - Micro: clima, relacionamentos, detalhes de diálogo
- Variáveis principais:
  - Sincronia
  - Ruptura
  - Confiança de Lyra
  - Status de Jude

## Paradoxo e Fricção
- Ações arriscadas geram Fricção Entrópica:
  - penalidade narrativa (visuais, hemorrágia ocular)
  - bloqueio de certas escolhas futuras
- Paradoxo direto leva ao caminho do Final Paradoxal

## Inventário e itens
- Inventário narrativo leve:
  - Relógio quebrado
  - Diário de Kael
  - Foto antiga
  - Chave de acesso
- Itens clicáveis no cenário servem para:
  - ativar diálogos
  - desbloquear pistas
  - alterar estados de NPC

## Guardar progresso
- Auto-save no fim de cada fase
- Save manual na tela de menu da fase
- Mostrar breadcrumb de capítulo e ato
